# Intrusion detection interface

This Storybook is the living catalogue for operator-facing components and
workspaces. Stories document meaningful states, responsive behavior, content
boundaries, and interaction—not just a component’s default appearance.

## Interface principles

1. Put the next operational decision before supporting detail.
2. Keep observed production evidence separate from offline evaluation.
3. Preserve exact evidence through progressive disclosure and equivalent
   structured views.
4. Use text, shape, and semantics in addition to color.
5. Prefer native interaction semantics and visible labels.

The accessibility addon is configured to treat automated violations as errors.
Keyboard, screen-reader, zoom, and real-user testing remain required because
automated checks only cover part of WCAG.

Page-document rules for a single `main`, page-level `h1`, and landmark coverage
are disabled only inside isolated component canvases. Full application browser
tests enforce those rules against the assembled product, while every other Axe
rule remains an error in Storybook.
